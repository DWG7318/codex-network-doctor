# 版本规则

## 起始版本

GitHub 首个公开版本和标签为 `v0.1.0`。仓库根目录的 `VERSION` 是发布版本的唯一来源，
构建脚本未显式传入版本时读取该文件。

## 升级规则

小更新、缺陷修复和兼容性改进增加补丁位 `+0.0.1`：

```text
v0.1.0
v0.1.1
v0.1.2
```

较大的功能、架构或产品范围改动增加次版本位 `+0.1.0`，并把补丁位归零：

```text
v0.1.2
v0.2.0
v0.3.0
```

不发布二进制的纯文档修正可以不升级版本。每个新版本都必须同步更新 `VERSION` 和
`CHANGELOG.md`，并创建对应的 `v` 前缀 Git 标签。
